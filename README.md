# THE SYSTEM CRM v1.0.3

## Release notes
Релиз 1.0.3: стабильный автоапдейт и облачный сервер.

### New
- Автоматическая проверка и установка обновлений при запуске
- Настройка «Автоматически обновляться» в Настройках (можно отключить)
- Веб-версия CRM, доступная через браузер по тому же API
- Раздел «Настройки → Подписка» с кнопкой «Получить полный доступ» (демо-режим)
- Поддержка отделов (departments) на уровне сервера

### Added
- Внешний REST API с API-ключами, scopes и rate limiting
- Webhooks с подписью HMAC-SHA256 и повторными попытками доставки
- Журнал обращений к внешнему API
- Сервер задеплоен на Fly.io: работает регистрация, логин, компании, аналитика

### Fixed
- Веб-версия: скрыты нативные кнопки окна и добавлен экран входа/регистрации
- Хранение автонастройки в отдельном локальном файле (не синхронизируется с облаком)

## System requirements
- Windows 10 / 11 (64-bit)
- 2 GB RAM
- 500 MB free space
