# THE SYSTEM CRM v1.0.4

## Release notes
Релиз 1.0.4: исправлен ввод сумм, калькуляция и права менеджеров.

### Fixed
- Денежные поля: разделители тысяч прямо при вводе, символ валюты больше не мешает набору цифр
- Калькуляция сделки: маржа, налог и готовые множители пересчитываются и сохраняются
- Менеджеры могут создавать подрядчиков и сохранять расходы по сделкам
- Веб-версия: исправлена загрузка и сохранение данных через браузер
- Настройка валюты больше не слетает после перезагрузки
- Ошибки сохранения теперь показываются уведомлением вместо молчаливого сбоя

## System requirements
- Windows 10 / 11 (64-bit)
- 2 GB RAM
- 500 MB free space
- Internet connection (data syncs via cloud server)
